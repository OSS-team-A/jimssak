# 가구 종류별 크기 분포로 측정값 다듬기

`ai.measurement.size_prior`는 보정까지 마친 측정값을 **그 종류의 가구가 보통 갖는 크기** 쪽으로
당긴다. 모델 가중치 없이 실행되고, 서비스 분석기에서는 보정 바로 뒤에 자동으로 적용된다.

## 왜 필요한가

보정 후에도 일반 영상 측정값은 많이 흔들린다(로그 오차 표준편차 약 0.3). 개발용 장면 100개에서
오차를 나눠 보면 **절반 정도가 한 물건의 가로·깊이·높이에 똑같이 걸리는 배율 오차**였다
(깊이 모델이 그 물건까지의 거리를 통째로 틀리는 경우). 반면 실제 가구 크기는 종류마다 모여 있다.
의자 높이는 대개 45~90cm이고, 가로가 크면 깊이도 큰 식으로 치수끼리 같이 움직인다.

그래서 측정값과 "그 종류의 크기 분포"를 함께 보고 가장 그럴듯한 실제 크기를 고른다.
높이처럼 분포가 좁은 치수가 배율 오차를 알려 주므로 가로·깊이도 같이 바로잡힌다.

## 방법

한 물건의 측정 치수 `y`(로그 cm)에 대해

- 실제 크기 `x ~ N(μ, S)`: 종류별 평균·공분산. ARKitScenes 개발용 3D 상자 3,400여 개에서 구함
- 측정 `y = x + s + e`: `s`는 세 치수 공통 배율 오차(분산 τ²), `e`는 치수별 오차(분산 σ²)
- 결과는 사후 평균 `μ + S (S + τ²J + D)⁻¹ (y − μ)`. 못 잰 치수는 빼고 계산한다

τ²와 σ²는 보정 후 잔차에서 영상 종류(일반 영상·ARKit)마다 따로 구한다. 종류별 표본이 20개 미만인
라벨, 그리고 표준 규격·카탈로그로 따로 맞추는 침대·세탁기·냉장고(`standard_sizes`)는 건드리지 않는다.
지금 적용되는 라벨은 수납장·의자·선반·소파·스툴·테이블이다. 적용된 물품에는 `size_prior_applied`가 붙는다.

## 결과

방 하나씩 빼고 채점했다. 빠진 방은 보정 배율, 크기 분포, 오차 모델 어디에도 쓰지 않았다.
평균 절대오차(cm)와 상대오차 10% 이내 비율이다.

**개발용 장면 100개** (방 42개, 치수 213개씩)

| 영상 | 단계 | 가로 | 깊이 | 높이 | 전체 | 10% 이내 |
|---|---|---:|---:|---:|---:|---:|
| 일반 영상 | 보정만 | 16.2 | 10.1 | 11.0 | 12.5 | 35% |
| 일반 영상 | **보정 + 크기 분포** | **13.9** | **6.6** | **9.1** | **9.9** | **42%** |
| ARKit | 보정만 | 13.0 | 8.9 | 8.7 | 10.2 | 41% |
| ARKit | **보정 + 크기 분포** | **12.4** | **6.5** | **7.7** | **8.9** | 41% |

**한 영상에 가구 여러 개 장면** (`--scene`, 치수 237개씩)

| 영상 | 보정만 | 보정 + 크기 분포 | 10% 이내 |
|---|---:|---:|---|
| 일반 영상 | 12.0 | **11.0** | 32% → 39% |
| ARKit | 12.0 | **10.6** | 43% → 41% |

일반 영상(서비스 조건) 오차가 12.5 → 9.9cm로 약 20% 줄었다. 두 번째 장면 묶음은 같은 100개 장면을
다르게 자른 것이라 완전히 독립된 확인은 아니다.

## 한계

- 크기 분포가 ARKitScenes(대부분 미국 가정) 가구에서 나왔다. 한국 가구와 분포가 다르면 효과가 줄 수 있다.
- 분포에서 많이 벗어난 특이한 가구(아주 긴 소파 등)는 평범한 크기 쪽으로 작게 당겨질 수 있다.
  그래서 측정값이 분포보다 확실할수록(오차가 작을수록) 덜 당긴다.
- AI 1 품목 중 책상·옷장·서랍장·TV는 ARKitScenes에 라벨이 없거나 적어서 아직 적용되지 않는다.
- 최종 평가용 장면으로는 아직 채점하지 않았다. 개선을 마친 뒤 한 번만 돌린다.

## 다시 학습하기 (맥, 몇 초)

```bash
python -m ai.measurement.size_prior fit outputs/arkitscenes-dev-objects.csv \
  outputs/dev-eval-100/truth.json outputs/dev-eval-100/dav2.json \
  --calibration ai/measurement/calibration/depth-anything-v2.json \
  --metadata outputs/arkit-depth-fix/metadata.csv \
  --output ai/measurement/calibration/size-prior-depth-anything-v2.json
```

측정 결과 하나에 직접 적용하려면 보정한 결과에 `apply`를 쓴다.

```bash
python -m ai.measurement.size_prior apply outputs/result-calibrated.json \
  --prior ai/measurement/calibration/size-prior-depth-anything-v2.json \
  --output outputs/result-prior.json
```
