# 세탁기·냉장고 제품 크기로 당기기

세탁기와 냉장고는 모델이 많아도 크기가 몇 무리로 몰려 있다. 그래서 일반 영상으로 잰 크기를
실제 제품 크기 쪽으로 당기면 오차가 줄어든다. `ai/measurement/standard_sizes.py`의
`pull_to_catalog`가 이 일을 하고, 침대 규격 맞추기와 같은 단계(`snap`)에서 실행된다.

## 방법

1. 제품 목록의 모델마다, 잰 가로·깊이·높이와 얼마나 맞는지 점수를 매긴다.
   - 세 치수를 함께 본다.
   - 측정 오차 폭(보정 후 log 표준편차, 가로·깊이 약 0.27, 높이 약 0.23)을 고려한다.
2. 점수를 가중치로 모델 크기를 평균한다(log 공간). 잰 값과 가까운 모델일수록 많이 반영된다.
3. 결과에 `appliance_catalog_prior`를 붙인다. v2.0 결과에는 `size_adjustment: "catalog_prior"`로
   나간다.

측정 축은 다른 가구와 같다. 가로는 바닥의 긴 변, 깊이는 짧은 변이다. 소형 냉장고는 제품표의
깊이가 폭보다 길어서, 측정 축에서는 가로와 깊이가 바뀐다.

## 검증 (시뮬레이션)

실제 세탁기·냉장고를 찍은 개발 영상이 없어서 다음처럼 검증했다.

1. 목록의 모델 하나를 실제 제품으로 둔다.
2. 그 크기에, 실제 개발 영상에서 다른 가구를 잰 보정 후 오차(방 단위 교차검증)를 곱한다.
3. 나머지 모델만으로 당긴다. 채점하는 모델은 목록에서 빠지므로 정답을 미리 아는 효과가 없다.

모델마다 200번 반복했다.

일반 영상, 중앙 상대오차 (괄호 안은 10% 이내 비율)

| 제품 | 경로 | 가로 | 깊이 | 높이 | 부피 |
|---|---|---|---|---|---|
| 세탁기 | 보정만 | 20.5% (21%) | 20.4% (30%) | 11.1% (45%) | 29.7% |
| 세탁기 | 제품 크기로 당김 | 8.5% (57%) | 6.0% (80%) | 6.9% (68%) | 19.1% |
| 냉장고 | 보정만 | 20.5% (21%) | 20.4% (30%) | 10.5% (46%) | 28.4% |
| 냉장고 | 제품 크기로 당김 | 10.0% (50%) | 10.8% (46%) | 4.9% (75%) | 23.8% |

- ARKit 영상도 비슷하게 좋아졌다. 세탁기 가로 14.8% → 9.0%, 냉장고 높이 9.2% → 4.7%.
- 부피 오차는 치수 오차보다 덜 줄어든다. 세 치수가 같은 모델 쪽으로 함께 당겨지면서 오차가
  같은 방향으로 쌓이기 때문이다.
- 이 숫자는 가전 측정 오차가 다른 가구와 비슷하다는 가정에 기댄다. 실제 촬영으로 다시
  확인해야 한다.

```bash
python experiments/size-estimation/simulate_appliance_prior.py outputs/dev-eval-scene/truth.json outputs/dev-eval-scene/dav2.json --metadata outputs/arkit-depth-fix/metadata.csv
```
