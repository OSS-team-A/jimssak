# 침대 표준 크기 맞추기

침대는 매트리스 규격이 몇 가지로 정해져 있다. 그래서 일반 영상으로 잰 침대 크기를 가장
가까운 규격으로 바꾸면 실제 크기에 더 가까워진다. `ai/measurement/standard_sizes.py`가 이
작업을 하고, 크기 보정(`calibration apply`) 다음에 실행한다.

## 규격

측정 기준은 다른 가구와 같다. 가로(width)는 바닥의 긴 변으로 침대 길이에 해당하고,
깊이(depth)는 짧은 변으로 매트리스 폭에 해당한다.

| 지역 | 규격 (매트리스 폭 × 길이, cm) |
|---|---|
| `kr` (서비스 기본값) | 싱글 100×200, 슈퍼싱글 110×200, 더블 140×200, 퀸 150×200, 킹 160×200, 라지킹 180×200 |
| `us` (ARKitScenes 개발 평가용) | 트윈 97×191, 풀 137×191, 퀸 152×203, 캘리포니아 킹 183×213, 킹 193×203 |

- 프레임과 헤드보드 여유분으로 길이에 8cm를 더한다. 폭에는 더하지 않는다.
  - 개발 침대 119개를 가장 가까운 미국 규격에 맞춰 보고 실제와의 차이 중앙값으로 정했다.
- 높이는 프레임 종류마다 달라서 측정값을 그대로 둔다.
- 측정 오차 폭(보정 후 log 표준편차 약 0.27)을 고려해, 가장 그럴듯한 규격을 고른다.

## 표시

- 규격으로 맞춘 침대에는 `bed_standard_size`와 `bed_standard_size:<규격>`을 붙인다
  (예: `bed_standard_size:queen`).
- 어떤 규격과도 1.8배 넘게 차이 나면 측정값을 그대로 두고 `bed_size_nonstandard`를 붙인다.
  사용자가 확인해야 하는 침대다.

## 실행

```bash
python -m ai.measurement.standard_sizes apply outputs/result-calibrated.json --region kr --output outputs/result-beds.json
```

## 검증 (시뮬레이션)

개발 장면 영상에는 침대 전체가 한 화면에 들어온 경우가 없어서, 침대를 실제로 측정해 채점할
수는 아직 없다. 대신 이렇게 검증했다.

1. 개발 분할의 실제 침대 크기 119개를 가져온다.
2. 실제 개발 영상의 다른 가구에서 나온 보정 후 오차를 뽑아 곱한다. 보정은 방 단위
   교차검증으로 학습한 것이다.
3. 그 값을 미국 규격으로 맞춘다. 여유분은 그 침대의 스캔을 빼고 다시 정한다.

| 경로 | 축 | 보정만: 중앙 상대오차 | 보정만: 10% 이내 | 규격 맞춤: 중앙 상대오차 | 규격 맞춤: 10% 이내 |
|---|---|---:|---:|---:|---:|
| 일반 영상 | 길이 | 20.5% | 22% | 4.5% | 86% |
| 일반 영상 | 폭 | 20.6% | 29% | 13.5% | 40% |
| ARKit | 길이 | 14.8% | 35% | 4.4% | 82% |
| ARKit | 폭 | 14.9% | 36% | 12.0% | 43% |

- 규격에서 벗어났다고 판단해 그대로 둔 비율은 일반 영상 2.3%, ARKit 7.1%였다.
- 길이는 규격이 거의 하나라서 크게 좋아진다. 폭은 규격 간격(10~20cm)이 측정 오차보다
  작아서 이웃 규격으로 잘못 고르는 경우가 있다. 그래도 측정값보다는 가깝다.
- 이 숫자는 침대 오차가 다른 가구 오차와 비슷하다는 가정에 기댄 것이다. 실제 침대 영상으로
  다시 확인해야 한다.

```bash
python experiments/size-estimation/simulate_bed_snap.py outputs/arkitscenes-dev-objects.csv outputs/dev-eval-scene/truth.json outputs/dev-eval-scene/dav2.json --metadata outputs/arkit-depth-fix/metadata.csv
```
