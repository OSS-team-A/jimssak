# 자유 이동형 프로토타입 이전의 크기 추정

기존 파이프라인은 외부에서 받은 동일 물체 마스크와 미터 단위 카메라 투영 행렬로
여러 프레임을 합친다. 깊이를 기하에 정렬하고, 여러 시점과 맞지 않는 거리 점을
제외한다. 두 프레임의 윤곽이 함께 지지하는 잘린 끝부분은 기하 점으로 보완한다.

ARKitScenes 영상의 3D 주석을 비교 기준으로 사용했다. 아래 수치는 가로·깊이·높이
순서의 절대오차(cm)이며, 같은 입력과 모델로 끝부분 복원 직전과 직후를 비교했다.

| 가구 | 복원 직전 | 복원 직후 |
|---|---|---|
| 나무 테이블 | 13.8 / 5.2 / 6.9 | 13.8 / 5.2 / 6.9 |
| 수납형 오토만 | 42.1 / 22.9 / 9.4 | 11.8 / 25.3 / 9.4 |
| 원목 수납장 | 5.5 / 9.1 / 18.9 | 5.5 / 9.1 / 18.9 |
| 흰색 협탁 | 10.5 / 5.1 / 측정 불가 | 10.5 / 5.1 / 측정 불가 |

처음 깊이 정렬을 적용한 나무 테이블 폭은 128.9cm였고 이상치 필터 적용 이후
87.8cm였다. 기준 폭은 74.0cm다. 이 영상에서는 카메라 위치를 데이터셋에서 받았다.
이전 `IMG_3898.MOV` 실험은 실측값과 가정한 초점거리로 카메라를 조건부로 계산했다.
