# 최초 Issue로 등록할 작업

GitHub의 기능 작업 템플릿으로 아래 작업을 등록하고 담당자를 지정합니다.

| 작업 | 완료 기준 |
|---|---|
| AI 공통 규격과 평가 샘플 확정 | 동일 원본 SHA-256, 프레임/좌표/단위 및 JSON 검증 합의 |
| AI 1: 실제 탐지 및 추적 | YOLO/BoT-SORT 어댑터, 프레임별 JSON, 중복/누락 측정 |
| AI 2: metric depth 및 크기 검증 | 카메라 보정, 척도 확보, 실측 비교 오차표 |
| Backend: 영상 업로드 및 분석 작업 | 저장 정책/용량 제한, 작업 상태 API, 실제 파이프라인 연결 |
| Frontend: 영상 업로드 및 목록 보정 | 로딩/실패 처리, 물품 목록 편집과 확인 |
| 통합: 이사 전후 매칭 | object_id 연결, 미확인/파손 의심 상태와 사용자 검토 |

실제 모델을 채택할 때 버전/모델 라이선스/가중치 출처와 GPU 환경을 기록합니다.
현재 AI 의존성에는 PyTorch/Ultralytics/OpenCV를 포함하지 않았으며 모델도 다운로드하지 않습니다.
